Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun: a program that writes one one-line comedy joke to `/output/entry.txt`.

The joke: "I started jogging to clear my head, but now I just have the same thoughts, only out of breath and further from home."

## Run

```sh
node main.ts
```

This writes the joke as a single line (116 characters) to `/output/entry.txt`.
